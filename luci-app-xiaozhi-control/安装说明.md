# 把 luci-app-xiaozhi-control 装进 798X 源码树

## 方式一：放进源码树 package/（推荐，自包含）

从仓库 clone `openwrt-app` 分支，它同时包含后端和 LuCI 两个包：

```sh
git clone -b openwrt-app <仓库地址>.git <798X源码>/package/diy/luci-app-xiaozhi-control
```

结构：
```
package/diy/luci-app-xiaozhi-control/
├── openwrt-xiaozhi-api/
└── luci-app-xiaozhi-control/
```

（也可以把 `luci-app-xiaozhi-control/` 单独放到 `package/utils/` 或 feeds 下，只要 `make menuconfig` 能看到即可。）

## 方式二：放进 luci feed（标准 luci-app 位置）

```sh
cd <798X源码>
./scripts/feeds update luci
cp -r luci-app-xiaozhi-control/ feeds/luci/applications/luci-app-xiaozhi-control/
./scripts/feeds install luci-app-xiaozhi-control
```

## 编译

25.12 用 apk 格式。**分开编译**（一次编两个会拉起依赖链）：

```sh
cd <798X源码>
make menuconfig
# LuCI  --->  3. Applications  --->  <*> luci-app-xiaozhi-control
# 顺带确认 Utilities ---> xiaozhi-api 也勾上

make package/diy/luci-app-xiaozhi-control/luci-app-xiaozhi-control/compile V=s
```

产物：
```
bin/packages/aarch64_cortex-a53/base/luci-app-xiaozhi-control-1.0-r1.apk
```

## 安装

```sh
scp luci-app-xiaozhi-control-1.0-r1.apk root@<路由器IP>:/tmp/
ssh root@<路由器IP> 'apk add --allow-untrusted /tmp/luci-app-xiaozhi-control-1.0-r1.apk'
```

LuCI 菜单刷新后（或重启 uhttpd / 重登），在 **服务（Services）→ 小智控制** 下出现配置页面。

## 页面功能

左栏配置：
- token、控制类总开关
- 各功能独立开关：在线设备、WAN 状态、系统状态、端口映射、映射列表、静态路由查询/添加/删除

右栏状态（实时读取，无需保存）：
- 在线设备、端口映射列表、静态路由列表

桌面端两栏并排，窄屏自动堆叠。

## 依赖

- luci-base、xiaozhi-api（apk 会自动装）
- ACL 声明了 xiaozhi-api / firewall 的 UCI 读写权限
