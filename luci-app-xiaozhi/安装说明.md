# 把 luci-app-xiaozhi 装进 798X 源码树

## 方式一：放进源码树 package/（推荐，自包含）

这个 app 的 Makefile 是自包含的（不依赖 luci.mk 的相对路径），直接放源码树任意 package 目录都能编：

```sh
cp -r luci-app-xiaozhi/ <798X源码>/package/utils/luci-app-xiaozhi/
```

（也可以放 `package/luci/` 或 `package/feeds/luci/`，只要 `make menuconfig` 能看到即可。）

## 方式二：放进 luci feed（标准 luci-app 位置）

```sh
# 先初始化 feeds
cd <798X源码>
./scripts/feeds update luci
# 放到 luci feed 的 applications 下
cp -r luci-app-xiaozhi/ feeds/luci/applications/luci-app-xiaozhi/
./scripts/feeds install luci-app-xiaozhi
```

## 配置与编译

```sh
cd <798X源码>
make menuconfig
# LuCI  --->  3. Applications  --->  <*> luci-app-xiaozhi
# 顺带确认 xiaozhi-api 也勾上（Utilities ---> xiaozhi-api）

make package/utils/luci-app-xiaozhi/compile V=s
```

产物：
```
bin/packages/aarch64_cortex-a53/base/luci-app-xiaozhi_1.0-1_all.ipk
```

## 安装

```sh
opkg install luci-app-xiaozhi_1.0-1_all.ipk
```

LuCI 菜单刷新后（或重启 uhttpd / 重登），在 **服务（Services）→ 小智 API** 下出现配置页面。

## 这个页面包含

- 通用：token、控制类总开关
- 功能开关：5 个功能各自的 allow
- 在线设备：ARP + OUI 厂商列表（只读展示）

## 依赖

- luci-base、xiaozhi-api（opkg 会自动装）
- ACL 已声明 xiaozhi-api 和 firewall 的 UCI 读写、/proc/net/arp 与 /tmp/oui.csv 读取
