# 在 ling/798X (ImmortalWrt MT798x) 上编译

## 源码树情况（已确认）
- 完整 ImmortalWrt 源码树，25.12 分支，内核 6.12
- 目标平台：`mediatek/filogic`（MT7981 / MT7986）
- 我们的包属通用 shell 包，与芯片无关，任何 defconfig 都能编

## 一、放包

把 `openwrt-xiaozhi-api/` 整个目录放到源码树的 `package/utils/` 下：

```sh
cp -r openwrt-xiaozhi-api/ <798X源码>/package/utils/xiaozhi-api/
```

放好后结构应是：
```
package/utils/xiaozhi-api/
├── Makefile
└── files/
    ├── routerapi
    └── xiaozhi-api.config
```

## 二、配置（选一个 defconfig）

源码根目录有现成的 defconfig。按你的路由器选，比如 AX3000：

```sh
cd <798X源码>
cp defconfig/mt7981-ax3000.config .config
make defconfig
```

然后在菜单里勾上我们的包：

```sh
make menuconfig
# Utilities  --->  xiaozhi-api  (勾选 <*>)
```

或者直接命令行勾选，不进菜单：

```sh
echo 'CONFIG_PACKAGE_xiaozhi-api=y' >> .config
make defconfig
```

## 三、编译

只编这一个包（最快）：

```sh
make package/utils/xiaozhi-api/compile V=s
```

产物在：
```
bin/packages/aarch64_cortex-a53/base/xiaozhi-api_0.1-1_aarch64_cortex-a53.ipk
```

（MT798x 是 ARM Cortex-A53，架构名 `aarch64_cortex-a53`）

## 四、安装到路由器

```sh
scp bin/packages/aarch64_cortex-a53/base/xiaozhi-api_*.ipk root@路由器IP:/tmp/
ssh root@路由器IP
opkg install /tmp/xiaozhi-api_*.ipk
```

opkg 会自动装依赖（uhttpd、jsonfilter）。如果没网装不了依赖，ImmortalWrt 默认已带 uhttpd，jsonfilter 通常也有。

## 五、验证

```sh
curl 'http://路由器IP/cgi-bin/routerapi?action=clients'
```

返回 JSON 就成了。

## 常见问题

**Q：菜单里找不到 xiaozhi-api？**
先跑 `make defconfig` 刷新，或确认包确实放在 `package/utils/` 下、Makefile 名拼写正确。

**Q：编译报缺少依赖？**
`./scripts/feeds update -a && ./scripts/feeds install -a` 先把 feeds 拉全，再编。

**Q：访问 CGI 返回 404 或 500？**
确认 uhttpd 配置里启用了 `/cgi-bin/`。ImmortalWrt 默认启用。检查 `/etc/config/uhttpd` 里有没有 `list cgi_prefix /cgi-bin`（老版本叫 `cgi_bin`）。
